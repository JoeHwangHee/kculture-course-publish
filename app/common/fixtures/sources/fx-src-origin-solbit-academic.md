# 솔빛고개

이 문서는 시험용으로 만든 가상 자료다. 실제 지명이 아니다.

솔빛고개는 소나무(솔) 사이로 아침 햇빛이 비쳐 드는 고개라는 뜻이다.
가상 지명 사전 2022년 7월 1일 판에 실린 풀이이며, 고개 아래 역 이름도 여기서 왔다.
