# 원자료: 서울교통공사 역명의 유래(OA-12036)

이 폴더는 색인하지 않는다. 색인 대상은 `app/data/bulk/`이다. 여기 둔 CSV는 변환 전 원자료의 UTF-8 사본이고, 변환 결과를 원본과 대조하거나 다시 변환할 때 쓴다. `app/sandbox/build_kb.sh`는 이 폴더를 모으지 않는다.

## 출처와 라이선스

- 자료: 서울 열린데이터광장 OA-12036 「서울교통공사_역명의 유래」
- 제공: 서울교통공사
- 주소: https://data.seoul.go.kr/dataList/OA-12036/S/1/datasetView.do
- 라이선스: 공공누리 제1유형(출처표시)
- 내려받은 날: 2026-10-07(팀장이 내려받음)

## 파일과 sha256

| 파일 | 인코딩 | sha256 |
|---|---|---|
| 원본(저장소에 넣지 않음) | CP949 | `9a9728f2c26c14baed7ae945f9a54ae74ac93aebc890980cf1cf39936ec91f17` |
| `OA-12036_station_name_origin.csv`(이 폴더) | UTF-8(BOM 없음) | `f16578b47b2a7e185c0dce95af25fb3aa67d54687a6952cf5a9a9054b297aaaa` |

- 사본은 원본을 CP949로 읽어 UTF-8로 다시 쓴 것이다. 행 순서와 값은 바꾸지 않았다. 줄 끝은 원본과 같은 LF이고, 마지막 줄 뒤에 줄바꿈이 없는 것도 원본 그대로다.
- 행 수: 274(머리 줄 제외)
- 열: `지하철역ID`, `지하철역명`, `호선`, `역명유래`
- 지하철역ID는 274개가 모두 다르다. 같은 역명이 여러 호선에 있으면 행이 따로 있다(예: `시청` 01호선·02호선).

## 변환 결과(`app/data/bulk/station_origin/`)

- 행마다 `STN-<지하철역ID>.md` 한 파일, 모두 274개다. 형식은 `docs/contracts.md` 6절 설계 4.3·4.7을 따른다.
- 머리 정보(값은 JSON 문자열·배열 표기)
  - `source_id`: `STN-<지하철역ID>`
  - `title`: `<역명>역 역명 유래(<호선>)`
  - `publisher`: `서울교통공사`, `source_type`: `official`(설계 2.3의 공식 자료), `provenance`: `real`, `kind`: `origin`
  - `published`: 빈 값. 행마다 작성일이 없어 지어내지 않았다.
  - `url`: 위 데이터셋 주소
  - `about`: `[<역명>, <역명>역]`. 역명에 괄호가 있으면 괄호 앞 이름과 그 이름+"역"도 더한다(이 자료에는 괄호 있는 역명이 없다).
  - 계약 밖 추가 키: `line`(호선), `station_id`(지하철역ID). 코드는 쓰지 않아도 된다.
- 본문: `# <역명>역(<호선>) 역명 유래`, 빈 줄, 역명유래(아래 `<br/>` 규칙만 적용한 원문), 빈 줄, 출처 줄 `출처: 서울교통공사, 서울 열린데이터광장 OA-12036 「서울교통공사_역명의 유래」(공공누리 제1유형: 출처표시)`
- 역명이 이미 "역"으로 끝나는 `서울역`(지하철역ID 0426, 0150)은 "역"을 한 번 더 붙이지 않는다. 제목은 `서울역 역명 유래(<호선>)`, `about`은 `["서울역"]`이다.
- 역명유래는 고치거나 요약하지 않았다. 앞의 기호도 그대로 두었다(예: 0337 `대청`은 `-`로 시작한다).
- 원문에 든 HTML 줄바꿈 태그 `<br/>`(변형 `<br>`·`<br />`도 같게)는 md 본문에서만 태그 하나를 줄바꿈 하나로 바꿨다(5행 34개: 0245, 0337, 2533, 2565, 2643). 이 폴더의 CSV 사본은 원문 그대로다.
