# 지금 풀 수 없는 문제

각 항목: 무엇이 깨지나(재현 조건) / 영향 범위 / 지금 못 푸는 이유 / 가능한 방법.

## 1. 비밀값 검사 도구에 회귀 시험이 없다

- **무엇**: 예선의 `tests/test_secret_scan.py`(빼는 규칙 두 개를 고정하는 시험)를 복사하지 않았다. `scripts/secret_scan.py`의 패턴이나 예외를 고치면 검사가 조용히 약해져도 알 수 없다.
- **영향**: 키나 로컬 경로가 커밋에 섞여도 검사가 0건을 낼 수 있다. push 전 의무 검사가 이 도구 하나에 기대고 있다.
- **지금 못 푸는 이유**: 시험 파일을 더하는 것은 코드 변경이라 브랜치·독립 검토를 거쳐야 하는데, 2026-10-06 밤 작업 범위는 문서 정리였다 `[추론: 결정 기록 23:15 줄]`. 예선 시험은 예선 전용 예외(컨테이너 경로, 이력 문서 기준선)를 함께 고정하고 있어 그대로 옮기면 이 폴더 구조와 맞지 않는다. 세 도구는 표준 라이브러리만 쓰므로 시스템 `python3 -m unittest`로 시험을 만들 수 있는 상태다.
- **가능한 방법**: 도구를 고칠 일이 생기면 그 전에 키 모양·경로 모양 각 1행이 걸리고 평문 1행이 안 걸리는 최소 시험을 먼저 만든다. 고치지 않으면 지금 상태로 쓴다(2026-10-06 추적 파일 전체 검사 종료 0).
